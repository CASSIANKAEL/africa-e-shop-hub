# Africa E-Shop Hub

Créer le prototype SaaS e-commerce destiné aux commerçants africains. Implémenter une navigation moderne et responsive (sidebar desktop rétractable, menu mobile fluide) et le Dashboard principal avec données fictives réalistes (devises comme FCFA / XOF, chiffre d'affaires, volume de commandes, commandes à confirmer/confirmées/annulées, taux de confirmation Cash-on-Delivery, graphiques de ventes et activité récente). Prévoir une architecture TypeScript propre et modulaire (types, mock services) avec les routes prêtes pour les futurs écrans (Boutiques, Produits, Commandes, Détail commande, Clients, Abonnement, Paramètres).
